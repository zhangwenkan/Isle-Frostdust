# 海岛 HD-2D 样区 · 2026-11-07

本轮按照参考研究先打磨西岛主角活动区域（约 x=-18 至 4）与桥头，尚未按同一造型标准重建东岛。固定近距离主角跟随镜头，保留正午青蓝海天、侧视山路与左端断崖。

## 实际改动

- 所有模型编辑通过 `tools/blender_mcp_client.py` 调用真实 blender-mcp，在 Blender 5.1 中完成；Godot 不生成场景网格。主源文件 `assets/island_blender/nameless_island.blend`，游戏导入同目录 GLB。
- 替换西岛岩岸与主景岩组，增加不同走向的断裂面、嵌入的碎岩、错落的草皮边沿和垂挂植被；清除旧规则石层配件。
- 重做四棵西岛松树的弯曲主干、分枝、树根与不对称树冠。树冠使用有弯曲和厚度层次的像素叶簇面片，配合倾斜顶层投影；不再用大量亚像素松针堆细节。
- 增加原创有限调色板像素纹理：岩面、草皮、泥土、树皮、木纹、松叶、竹叶、蕨类和垂藤。纹理源稿在 `tools/pixel/paint_sample.py`，PNG 在 `assets/island_blender/pixel/`。没有使用第三方游戏图片作为资产。
- 修复 Godot 植被材质只保留颜色、丢失导入贴图的问题。透明叶片使用 alpha scissor，最近邻采样；尺寸按实际中景匹配。
- 山路改为不规则边沿，桥头补锚石与横木，木板纹理按板长方向排列。清掉样区的旧微小草叶，改成集中于树根、岩脚和路肩的植被群落。
- 切换至 Forward+，启用 SSAO 接触阴影、轻量光晕和基于深度的近远景虚化。主角与行走中景保持清楚。F 同时切换原生景深与深度后处理；旧按屏幕 Y 坐标模糊的 shader 已不再使用。
- 海面接收桥梁与岩石阴影，收弱连片波纹；浪花使用局部破碎形状。水面仍是风格化方案，未实现真正的场景倒影或物理海浪模拟。

## 验证与预览

在本机 Godot 4.6.1、Intel Arc 140T、Vulkan Forward+ 上运行并截图。`tools/verify_island_sample.gd` 检查导入场景、后处理表面、F 景深开关、出生点、桥头、桥面、断崖、D 行走和镜头跟随。检查输出与图片位于 `artifacts/hd2d-sample/`。

早期 640×360 短时 70 帧预览均值约 51 FPS（含初始化与截图，不作为长期性能基准）；检查未出现脚本、shader 或资源导入错误。随后按清晰度反馈，改为 1280×720 界面设计尺寸，默认窗口从 1600×900 进一步提升至 2560×1440（QHD，常称 2K），使用 canvas_items 拉伸让 3D 按实际窗口尺寸渲染；像素纹理仍使用最近邻采样。上述帧率属于调整前的低分辨率版本。Forward+ 需要 Vulkan 支持；兼容渲染下不会拥有同样的 SSAO 和原生景深效果。

此前源文件、GLB、游戏脚本和项目配置保存在 `artifacts/hd2d-sample/backup/`。本轮制作入口依次为 `sample_pass.py`、`sample_polish.py`、`sample_finish.py`，均须由 blender-mcp 执行，不能直接在系统 Python 中运行模型代码。Blender 源文件是后续手工调整的主要资产。

2026-11-07 分辨率验证：本机主屏 3200×2000，默认 2560×1440 窗口实际截图为 2560×1440；Vulkan 运行无报错。70 帧短时预览约 42 FPS（包含初始化与截图），记录位于 `artifacts/resolution-review/native-2560.log`，原生截图为同目录 `native-2560.png`。

这是用于继续美术评审的第一轮样区，不代表已经达到商业参考作品的完成度。下一步应针对画面反馈继续调整轮廓、像素色阶和植被疏密，再将确认的标准扩展到东岛。
