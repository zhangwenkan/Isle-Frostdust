# HD-2D 参考研究与当前场景问题

研究日期：2026-11-06。参考《逸剑风云决》《八方旅人／歧路旅人 II》《风之痕迹》。本次仅研究、分析与记录，没有改动场景或模型。

## 结论

当前场景仍是带二维人物的三维原型，尚未达到参考作品的像素美术和 HD-2D 完成度。上轮虽然通过 blender-mcp 操作 Blender，但模型主要由脚本批量构造，岩石、树冠与地形形态仍重复；换建模工具没有替代逐件造型、像素绘制和画面设计。不能以使用 Blender、网格数量或三角面数量作为美术精细度的证据。

应同时解决三件事：模型大中小形体的设计；贴图内部的像素形状、色阶与统一密度；围绕主角活动面组织的灯光、遮挡、景深和空气透视。

## 从画面能够观察到什么

### 1. 像素感首先存在于素材中

《逸剑风云决》的河岸图中，人物、树叶、草丛、岩面和木材都有能辨识的像素形状与明暗块。近处清晰，远处即使虚化仍保有大色块秩序。《歧路旅人 II》的石岸图中，每一组石块的亮面、暗缝、苔藓和草皮都构成连贯结构。

这支持的制作方向是：先设计材质的可读形状和像素色阶，再贴合三维几何与灯光。整张画面缩小至 640×360、开启最近邻采样，只会改变显示颗粒；它不会自动赋予普通纹理像素艺术设计。也不能据此推断参考游戏都以 640×360 渲染。

### 2. 精细度来自结构，而非堆细碎网格

参考中的岩岸有大尺度轮廓变化，中尺度石块、裂缝、断层，小尺度苔藓与缺口；植被以有体积、有疏密的叶簇组织。桥梁和岸边具有可信的接合关系。当前许多松针和绳索纤维在实际镜头下不足一个像素，细节会丢失或闪烁，而岩壁宽条带和重复石块仍然显眼。

植物可以采用精细三维主干、适合镜头的叶簇网格与像素透明贴图的混合资产。透明卡片本身不等于粗糙，逐叶建模也不自动等于精细。具体应通过同一镜头的样件比较决定。这里是本项目建议，不是声称三款游戏的每棵树都采用相同技术。

### 3. HD-2D 的层次依靠整幅构图

官方截图可见清晰的角色活动中景、更柔和的背景，以及前景树木或建筑的遮挡；受光区域、阴影与雾共同引导视线。《八方旅人》开发者也明确允许水使用三维表现，说明并不要求所有视觉元素采用同一种像素处理。

本项目要保留正午、海外孤岛的明亮氛围，不能为了接近《八方旅人》的部分截图而照搬黄褐调、重暗角或傍晚光。应使用短而清晰的投影，保护高光中的像素色阶，用冷暖和距离区分空间。

## 当前工程的具体问题

| 当前问题 | 工程中的原因 | 修改方向 |
| --- | --- | --- |
| 画面缩小了，但没有像素绘画的味道 | 纹理以连续噪声、规则条纹和随机变化为主；最近邻只改变采样 | 为岩面、草皮、树皮、叶簇和木材分别制作经过设计的像素纹理；统一相邻物体的世界尺度与纹理密度 |
| 岩壁像分层蛋糕，石块像重复多面体 | 大轮廓、岩层和破碎关系过于规则；增加细纹没有改变主要形态 | 通过 blender-mcp 逐件调整海蚀断面、岩台、裂隙走向和不同块体的嵌合，减少露在外面的均匀三角切面 |
| 松树稀疏且针叶杂乱，地面植被零散 | 分枝角度和层高过于规律，微小针叶被压成噪点；草丛缺少成片组织 | 先设计树冠与叶簇整体形状，再细化可见枝叶；草丛按路径边缘、背阴处和岩缝聚集 |
| 山路发白、草地偏平 | 日照把浅色贴图推亮，缺少足够的局部明暗与落地阴影 | 调整材质色阶和光照能量，补足树根、岩底、桥柱接触阴影；保留正午环境 |
| 前后景没有微缩摄影式的空间感 | `island_lens.gdshader` 按屏幕纵坐标模糊，没有读取深度；热雾也只关联画面上方 | 根据世界深度／角色焦平面实现景深；加入有明确距离的前景遮挡和背景雾层 |
| 人物与环境像两种画法 | 人物轮廓和纹理密度，与环境的碎面和杂点不匹配 | 保留现有角色形象，先围绕它建立环境像素密度、明暗层级与细节尺度，不擅自重画人物 |
| 海面像简单装饰纹样 | 当前水面材质为 unshaded 噪声与闪点，没有对场景的真实反射或岸边深度表达 | 在性能预算内改进岸边浅水、反射／倒影近似、浪花与礁石遮挡关系，避免覆盖整屏的重复闪点 |

## 建议的下一轮制作顺序

以下是根据参考提出的方案，不表示本次已经实现。

1. 先制作主角附近一个完整屏幕的样区：一段有转折的岩岸、一棵主景松树、一组岩石与蕨草、一小段山路和桥头。
2. 固定已经认可的中景镜头。在 Blender 中逐件做形体，UV 与像素纹理同步设计，按游戏中的实际显示尺寸检查。
3. 调好受光、阴影、材质色阶、角色落地与近远景深；用关闭后处理的画面检验资产本身是否成立。
4. 在角色移动时检查像素闪烁、纹理比例和叶簇可读性，再检查静帧。关键细节至少应在目标镜头下形成可辨识的像素块。
5. 样区效果达到目标后，以同一标准扩展其他区域；不要再次一次性批量替换整岛，却没有一个经过充分打磨的示范资产。

这条工作流仍严格遵守项目约定：模型与建模修改必须通过 blender-mcp 在 Blender 中完成；Godot 用于导入资产、场景装配、灯光、材质、镜头与玩法。
