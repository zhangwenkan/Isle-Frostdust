# 语域：什么口气说什么话

一场戏里可以换语域，不可以混在同一张嘴的同一句里。

## 五种语域

### 1. 开口（默认）

古龙白话短句。见 [voice.md](voice.md)。

用于：NPC 对白、主角可选台词、争吵、试探、临死一句。

### 2. 旁白 / 过场

金庸的清楚 + 梁羽生的一点余味。

规则：

- 先让玩家知道：在哪、看见谁、能不能走
- 景物最多两句，第三句必须回到人
- 不替玩家总结主题
- 不用「只见」「但见」开每段
- 武打：写身形、一声响、结果。不写内功运行路线

例（旁白）：

> 雨是从海面上走来的。  
> 桥那头的人没有打伞，也没有躲。

### 3. 名物

温瑞安的对仗、颜色、季节；或金庸式的意象名词。必须原创。

用于：刀剑、门派、招式、外号、地方、组织。

规则：

- 四个字不一定更好。两个字的地名往往更真
- 招式名是人物的自我认识，不是 UI 技能标签的翻译腔
- 同一门派的名字要像一家人，不要一个唐诗一个日漫
- 先查 `narrative/bible/`，避免撞名

### 4. 文书

真正的文言。短。

用于：信、残页、碑、判牍、祭文、门规。

规则：

- 不超过八句，游戏里可分页
- 故意写得比开口难懂一点，但关键信息仍要能被聪明玩家读出来
- 可缺字、可涂黑，缺的是钩子
- 不要用半文半白的「之」来冒充

例：

> 霜落孤屿。来者莫问归期。

### 5. 传闻

卧龙生的快与钩。茶馆、渔人、孩子、告示边上的闲话。

规则：

- 不可靠。至少有一句是错的或过时的
- 丢一个专名或一件物，不解释
- 口语，比开口更土一点

## 主角选项的语域

可选台词默认仍是古龙，但要让玩家感到**三种态度**，不是三种同义改写。

坏：

- 「你是何人？」
- 「请问尊姓大名？」
- 「报上名来！」

好：

- 「你是谁。」（硬）
- 「这岛还有别人吗。」（绕）
- 「……」（不答，古龙合法）

选项从玩家此刻能有的态度里长出来，不要为了文言而文言。

## 切换

同一角色可以在文书里文言、开口时白话。  
同一场可以从旁白（境）切到对白（冷）再切到传闻（钩）。

切的时候用空行或游戏指令，不要在一句里先「却说」再「哈哈」。
