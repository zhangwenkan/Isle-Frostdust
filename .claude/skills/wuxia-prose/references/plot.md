# 剧情整理与规划

用户会按段给口头思路。工具的工作不是立刻写成小说，是把散的话收成**能玩的结构**，再写这一场的文。

## 用户给一段时，先做的整理

用他们的词，补成这张表（未知就写未知，不许编）：

```
这场：
- 地点：
- 在场：
- 玩家进来前已发生：
- 玩家看见：
- 玩家能做：
- 结束条件：
- 结束时新知道：
- 结束时仍不知道：
- 钩子（一物 / 一口误 / 一个不答）：
- 人的变化（谁对谁的看法变了）：
```

这张表是「金庸的人」+「卧龙生的钩」。表不过关，不要写长对白。

## 更大的弧（有多段以后）

《孤屿霜尘》体量会很大。规划用章回，不用西式三幕术语跟用户说话。

建议层：

1. **卷** — 一块地理或一种关系（例如「无名屿」）
2. **回** — 一次可玩的单元（一晚、一座庙、一场雨）
3. **场** — 一个场景文件，对应 `narrative/scenes/` 一篇

每一回要能回答：

- 人：谁被逼着做了不愿做的事
- 义：谁的规矩破了
- 钩：下一回凭什么必须去

金庸负责「人为什么必须如此」。  
卧龙生负责「下一回凭什么必须去」。  
梁羽生负责「这一回的情绪像什么天气」。  
古龙负责「人怎么说话」。  
温瑞安负责「这回亮出的名与器叫什么」。

## 信息差

武侠好看，常常因为台上两个人各知道一半。

每场至少标一层：

| 层 | 谁知道 |
| --- | --- |
| 玩家 | 画面 + 已读文本 |
| 主角（若不全等于玩家） | |
| 对手 | |
| 旁观者 | |
| 作者 / 圣经 | 真相，玩家此刻不准知道 |

对白禁止把「作者层」说出来。古龙的莫名其妙，经常就是有人站在作者层，却只用跳题来碰一下。

## 钩子的质量

好钩子：

- 具体（一块缺角的玉，不是「一个秘密」）
- 可被下次捡起
- 今晚解释会变蠢的，就今晚不解释

坏钩子：

- 「此事另有隐情」（空）
- 旁白剧透
- 每个 NPC 临走都丢预言

## 与玩法对齐

这是游戏，不是连载小说。整理时问：

- 玩家能否走错、说错、打输？
- 失败是死、是伤、是被看轻、是丢一件东西？
- 选项是态度，还是真的分叉？

没说清的，在整理区列为「待你定」，不要擅自做成线性演出。

## 连续性

新场开写前读：

- `narrative/bible/plot-arc.md`
- `narrative/bible/characters.md`
- 相关已有 `narrative/scenes/`

打架时：**停笔**，把冲突亮给用户，让他们改圣经或改这场。不要默默圆。
