# 剧情与文案

《孤屿霜尘》的故事不写在引擎场景里，写在这里。

| 目录 | 用途 |
| --- | --- |
| `inbox/` | 你的口头稿：走向、人设、半截对话 |
| `scenes/` | 转化后的场景稿，一篇一场 |
| `bible/` | 你点过头的世界、人物、弧、专名 |
| `_example/` | 工具示范，**不是**正史 |

转化器是项目 skill：`.claude/skills/wuxia-prose/`。

口诀：**骨架金庸，钩子卧龙，意境梁羽，名物温瑞，开口古龙。**

对白默认古龙白话短句（冷、跳、莫名其妙），不是之乎者也，也不是周星驰。文言气放在旁白和文书。

你还没口述主线之前，bible 保持空，不要替你编。下一则口头稿丢过来，或写进 `inbox/` 即可。
